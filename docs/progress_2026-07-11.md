## 2. Supervisor's baseline training code (commit 545a4d0, pulled Jul 10)

SFT + RLVR/GRPO controls on VisualPRM400K-v1.1-Raw and LLaVA-CoT-100k. Controls:
`BASE_MODEL=Qwen/Qwen2.5-VL-3B-Instruct, DATA_RATIO=0.01, MAX_SEQ_LEN=4096, SEED=42,
TOKEN_BUDGET=1e6`; reward ablations limited to accuracy/format ("do not pass `ours`");
all scripts default `DRY_RUN=1`.

How it consumes v1.1-Raw rows:

- **SFT** (`src/train/sft.py`): prompt=`question`, response=`response` (field-priority
  fallback in `normalize_supervised_example`); `steps_with_score`/`analysis`/`answer` are
  **ignored**; no correctness filtering; collator masks only padding in labels (prompt
  tokens are trained on too). → SFT imitates raw rollouts verbatim, including wrong ones.
- **RLVR** (`rlvr_grpo.py:120`): parquet `ground_truth` = the **entire `response` text**,
  not the `answer` field. `accuracy_reward` (`baseline_rewards.py`) only knows
  `<answer>/<final>/<conclusion>/####` extraction — VisualPRM uses "Final answer: ..",
  so extraction returns the whole trace, exact match never fires, and the first-number
  fallback usually compares "1." step markers → **near-degenerate accuracy reward on
  VisualPRM**. `format_reward` gives the dataset's own format only 0.5.
- **To raise with supervisor**: set `ground_truth = answer` and add a `Final answer:`
  pattern to `_extract_answer` for VisualPRM runs.

## 4. Design decision for our match reward (addresses reference noise)

Matching rollouts against `response` as gold inherits its noise (10.4% provably wrong
traces; individual bad steps elsewhere). The dataset itself provides the fix — per-step
MC reliability scores:

1. **MC-score-weighted bipartite matching** (primary): weight each reference step's match
   contribution by its `steps_with_score` score, so a score-0.0 step (e.g. a wrong
   "Final answer: A") neither costs nor pays anything.
2. **Hard answer-correctness term** from the `answer` field (already a planned component).
3. Optional: filter references to the 152.6k clean subset, or use `analysis` as a sparse
   gold reference (23.7% coverage).

This soft-reference design is something the accuracy/format baseline cannot do —
strengthens the comparison story.
